# DRV8825 固定脉冲对照测试

用于排查：micro-ROS 固件收到一次非零速度后，电机仍反复转停。
本固件用普通 GPIO 输出约 200 STEP 脉冲/秒，绕开 micro-ROS、TIM1 和
AccelStepper。它是诊断工具，不是打印固件。

## 操作

1. 停止 micro-ROS agent 和所有速度发布节点，避免它们占用 USB 串口。
2. 保持接线不变：D14/PA9 接 STEP，D13/PA10 接 DIR。
3. Arduino IDE 选择 **Portenta H7 Main Core (M7)**，烧录同目录的
   `DRV8825_pulse_test.ino`。上电和烧录后不会自动发脉冲。
4. 打开串口监视器，波特率 115200。发送 `g`，观察这一次 20 秒测试中
   是否仍有“转 2 秒、停 3 秒”的循环。换行设置不限。
5. 测试结束会自动停止发脉冲；运行中发送 `s` 可以提前停止。
   正常完成后只停一次，不会自动重复。保存 `DONE ...` 整行以及电机现象。
6. 测试结束后重新烧录 `../DRV8825_microros/DRV8825_microros.ino`，
   关闭串口监视器，再启动 micro-ROS agent，恢复 ROS 控制。

200 是实际 STEP 脉冲/秒，没有乘 32。对于 1.8°、1/32 细分电机，
约为 1.875 rpm，20 秒转 0.625 圈。请观察轴上的标记，而不只凭声音。
停止发脉冲不等于关闭驱动器使能；本固件不控制 ENABLE、RESET 或 SLEEP。

## 如何判读

正常的整次测试应有约 4000 个 `pulses`、约 20000 的 `elapsed_ms`、
约 5000 的 `max_gap_us` 和 0 个 `readback_errors`。GPIO、串口检查和
系统中断有开销，所以脉冲数和周期不会精确等于这些值。

- `pulses` 统计代码执行 STEP 拉高的次数，不是编码器计数。
- `max_gap_us` 统计相邻 STEP 拉高调用的时间间隔，也包含启动和停止前
  的间隔。若软件停顿约 3 秒，预期能看到百万微秒量级的值。
- `readback_errors` 统计写入高/低后，Arduino STEP 引脚读回值不一致的次数。
  它检查板端电平，不能证明驱动器端波形、电流或电机转动正常。
- 时间来自 Arduino 自身时钟；这不是独立的示波器测量，CPU 或时钟异常
  仍可能影响结果。测试中的中断未被禁用。

| 观察结果 | 下一步 |
| --- | --- |
| 本测试持续转动，而 micro-ROS 固件反复转停 | 继续对照 TIM1、系统运行状态和 ROS 固件，不改标定表 |
| 电机仍转停，但 `max_gap_us` 约 5000 且读回无错误 | 软件循环未观测到秒级停脉冲；优先检查驱动器、电源、接线及故障信号 |
| `max_gap_us` 达到百万量级，或读回有错误 | 继续检查 Arduino 运行停顿、引脚冲突或板端信号；不能据此直接判定驱动器故障 |

原有 `DRV8825_serial.ino` 将输入乘 32，并用 `readStringUntil()` 解析串口，
所以直接向它发送 200 不能作为这里的等频率对照。
